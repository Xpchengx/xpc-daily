🧽 Xpc每日任务 · 部署指南

跟着走一遍，手机上就能用了。全程约 15 分钟。

1建一个 GitHub 仓库

  1. 打开 github.com 登录
  2. 右上角 + → New repository
  3. 仓库名填 xpc-daily
  4. 选 Public（免费账号只有公开仓能开 Pages）
  5. 不要勾任何初始化选项（README / .gitignore 都别勾）
  6. 点 Create repository
公开仓库会不会泄露我的待办？不会。
仓库里只有代码，一个字的数据都没有。你的待办和日志存在两个地方：手机浏览器本地，和你的私有 Gist（Gist 单独设为私有，跟仓库公不公开无关）。

2把文件传上去

两种方式，选一个：

方式 A（推荐）：让我来推
把你的 GitHub 用户名发我，我执行推送，中间会弹一个 GitHub 登录窗口，你登录一下就行。密码不经过我。
方式 B：自己敲命令
在工作台文件夹里右键 →「在终端中打开」，粘贴这三条（把 USER 换成你的用户名）：
git remote add origin https://github.com/USER/xpc-daily.git
git branch -M main
git push -u origin main

3开启 GitHub Pages

  1. 仓库页面 → 顶部 Settings
  2. 左侧 Pages
  3. Source 选 Deploy from a branch
  4. Branch 选 main，文件夹 / (root) → Save
  5. 等 1–2 分钟，刷新，页面顶部会出现你的网址：
https://USER.github.io/xpc-daily/
这个网址就是你的工作台，手机电脑都能开。国内访问 GitHub 时快时慢，打不开就多刷两次。

4加到手机桌面（变成 App）

  1. 手机浏览器打开上面那个网址（Safari 或 Chrome，别用微信内置浏览器）
  2. iPhone：底部「分享」按钮 → 往下滑 →「添加到主屏幕」
    安卓：右上角「⋮」→「添加到主屏幕 / 安装应用」
  3. 桌面上会出现 🧽 图标，名字是 Xpc
之后点开就是全屏的，没有地址栏，跟 App 一样。断网也能用。

5开启双端同步

先拿一个 token（只勾 gist 权限）：

  1. github.com → 右上角头像 → Settings
  2. 左下 Developer settings → Personal access tokens → Tokens (classic)
  3. Generate new token (classic)
  4. Note 填 xpc-daily，过期选 No expiration
  5. 只勾 gist 一项（别多勾）
  6. 生成后立刻复制 —— 关掉页面就再也看不到了，先粘到备忘录

然后：两台设备都打开工作台 → 设置 → 粘贴 token →「开启同步」。

token 只显示一次，务必先存备忘录。丢了只能重新生成一个，不费事但别偷懒。

常见问题

数据存在哪？
主要在你手机浏览器里，断网照用。开了同步后，云端（私有 Gist）多一份，用于两端对齐。备份文件下载后自己存好。
同步密码忘了怎么办？
没有找回功能。好在本地数据不会因为忘记密码而丢失 —— 重生成一个 token 填进去就行。所以先做一次「导出备份」永远是划算的。
换手机了怎么办？
新手机打开网址 → 设置里填同一个 token → 自动拉回所有数据。或者用「恢复备份」导入之前导出的 JSON。
为什么不能到点响铃提醒我？
网页没有后台推送，iOS 和安卓都限制了。想要真响铃，把固定提醒事项加到手机日历里，那个能响。
以后想加功能怎么办？
直接说「给我的工作台加个 XX 功能」。工程里每个功能都有独立的代码区块（标着 功能：XX START / END），新功能插进去不会碰坏已有的东西，改完我会重跑一遍测试。
