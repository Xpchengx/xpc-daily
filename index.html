💾 数据备份

你的数据主要存在这台设备的浏览器里，不在任何服务器上。
换设备、清理浏览器数据前，记得先导出备份。

🔄 双端同步

数据存在一个私有 Gist 里，只有你的 GitHub 账号能看到，走 GitHub 官方接口，不经第三方服务器。
本地那份始终在，断网照样能记。两台设备填同一个 token，会自动找到同一份数据。
token 只显示一次，生成时先粘到备忘录。

怎么拿：github.com → 右上角头像 → Settings → Developer settings
→ Personal access tokens → Tokens (classic) → Generate new token
→ 只勾 gist 一项 → 生成后复制（关掉就看不到了）

建议先导出一份备份再开。

📝 工作日志同步

日志默认只留这台设备——它经常夹带不想上云的内容。
打开之后，日志会和待办一起存进你的私有 Gist，手机电脑都能看。

改这个只影响以后的同步，已经写过的内容一条都不会丢。
建议两端设成一样：一端开一端关的话，关的那端推送时会把云端的日志覆盖掉。

📳 震动反馈

滚时间/日期滚轮时，每过一格手机轻震一下，手感接近系统控件。
安卓：可用，效果最好。
苹果 iPhone：Safari 至今不给网页开放震动接口，只能用变通办法试一下， 可能完全没反应 —— 没反应就关掉它，不影响别的。

🗂 卡片折叠

折叠状态会记住，也会同步到另一端。
